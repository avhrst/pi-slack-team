SVG is the editable source: 1440 × 1640, selectable text, accessible title/description, no scripts or external resources. PNG previews are exported at 2×: 2880 × 3280. Both languages use the same diagram geometry and matching `data-key` labels. They describe the checked-in architecture, not live agent status.

SVG — редаговане джерело: 1440 × 1640, текст із можливістю виділення, доступні заголовок/опис, без скриптів і зовнішніх ресурсів. PNG-прев’ю експортовано у масштабі 2×: 2880 × 3280. Обидві мови використовують однакову геометрію схеми й відповідні позначки `data-key`. Схеми описують архітектуру репозиторію, а не поточний статус агентів.

When updating, edit the same labels in both SVGs, export each SVG to its matching PNG at the dimensions above, and visually inspect both versions for text overflow, missing glyphs and incorrect arrows. Preserve the shared-history boundary and the distinction between tmux and RPC. Use an SVG renderer with a font that supports Ukrainian; the source declares DejaVu Sans / Arial fallbacks.

Під час оновлення змінюйте відповідні підписи обох SVG, експортуйте кожен SVG у відповідний PNG із зазначеними розмірами та візуально перевіряйте обидві версії на вихід тексту за межі, відсутні символи й неправильні стрілки. Зберігайте пояснення межі спільної історії та відмінності tmux/RPC. Використовуйте SVG-рендерер зі шрифтом, що підтримує українську; джерело декларує DejaVu Sans / Arial як запасні шрифти.
